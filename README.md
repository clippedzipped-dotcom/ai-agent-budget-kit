# AI Agent Budget Kit

Eén playbook voor solo makers die met AI-agenten een digitaal product willen verkopen — op €0 budget.

**Dit product bestaat. Dit repo hoost de verkooppagina.**

## Wat er in zit

- Pipeline-architectuur voor een zero-budget AI-verkooppipeline
- Fee-vergelijking (Payhip vs Gumroad vs Etsy) op een $19 product, met de $3-valkuil
- De gratis Novita model-ids die echt bestaat — `qwen/qwen3.6-plus` (1M ctx), `inclusionai/ling-3.1-flash`, `qwen/qwen3.5-plus`, `inclusionai/ling-3.0-flash-sante`, `apodex/apodex-1.1-mini`
- Credits-wachter: script dat elke 4 uur saldo checkt en onder $0,50 automatisch naar gratis model schakelt
- Drie fatale beginnerfouten en hoe je ze vermijdt
- 7-stappen uitvoeringsplan met tijdsduur per stap

## Waarom $19

Omdat $3-producten 25-40% van hun prijs aan vaste fees verliezen en $49 te veel is voor een eerste product.
